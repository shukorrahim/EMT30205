L3.1What is a timer?

In one sentenceA timer makes the PLC wait a set time before it does something: it is used for time delay.

There are two kinds of delay. An on-delay timer waits after the input turns ON before it switches the output ON. An off-delay timer keeps the output ON for a while after the input turns OFF. Press the buttons below and watch the two lamps.

On-delay (TON, TIM)

Input ON → wait → output ON. The most common timer.

Think of it: instant noodles. You pour hot water (input ON), wait 3 minutes, then eat (output ON). If you throw it away early, the waiting starts again from zero.
(Seperti mi segera: anda tuang air panas (input ON), tunggu 3 minit, kemudian baru makan (output ON). Jika anda buang awal, kiraan bermula semula dari sifar.)
Off-delay (TOF)

Input OFF → output stays ON for a while → output OFF. Less common.

Think of it: the light inside a car. You close the door (input OFF), but the light stays on a few seconds so you can find your seatbelt, then it goes off.
(Seperti lampu dalam kereta: anda tutup pintu (input OFF), tetapi lampu masih menyala beberapa saat supaya anda boleh mencari tali pinggang keledar, kemudian ia padam.)

L3.2The OMRON TIM instruction

In one sentenceTIM N #SV is an on-delay timer: while its input is ON, the present value (PV) counts down from the set value (SV) in steps of 0.1 s, and at 0 the timer's contact TIM N turns ON.
Think of it: the countdown on a microwave. You set the time, it counts down to show the time left, and it beeps at 0. Open the door (input OFF) and it goes back to the time you set.
(Seperti kiraan detik pada ketuhar gelombang mikro: anda tetapkan masa, ia mengira turun menunjukkan baki masa, dan berbunyi pada 0. Buka pintu (input OFF) dan ia kembali ke masa yang ditetapkan.)

Tap each part of the timer rung to see what it does.

From seconds to SV

The SV is the time in tenths of a second, written as a 4-digit number with # in front. # means "a constant" (a fixed number, not an address). So multiply the seconds by 10.

L3.4Off-delay timer

In one sentenceThe CPM1A has no ready-made off-delay instruction, so we build one: a self-holding output plus a TIM that runs after the input turns OFF.

The output turns ON at once with switch 00000. When the switch turns OFF, the output holds itself ON (the self-holding circuit from Lab 2, L2.3) and TIM 000 starts. After 5 s the NC contact TIM000 breaks the hold and the lamp goes OFF. Try a long ON, a short ON, and turning it ON again while the timer is running.

Why rung 1 uses NOT 00000: the timer must run only while the input is OFF and the output is still ON. If the input comes back ON, the timer resets and the output simply stays ON.

L3.5Reading a timing diagram

In one sentenceA timing diagram shows time from left to right and draws each signal as a line: up means ON, down means OFF.
Think of it: a bus timetable drawn as a picture. Time runs along the bottom, and each line shows when something is happening.
(Seperti jadual bas dalam bentuk gambar: masa bergerak di sepanjang bahagian bawah, dan setiap garisan menunjukkan bila sesuatu berlaku.)

L3.6Cascading timers

In one sentenceCascading means two or more timers in a chain: when the first one times out, its contact starts the second one.
Think of it: a relay race. The second runner starts only when the first one hands over the baton, so the total time is both legs added together.
(Seperti lari berganti-ganti: pelari kedua hanya bermula apabila pelari pertama menyerahkan baton, jadi jumlah masa ialah kedua-dua pusingan dicampur.)

Why cascade? One TIM can count to only #9999 = 999.9 s (about 16.7 minutes). For a longer delay, chain timers. Cascading is also used for sequences: each timer's contact can switch on a different output, one after another (traffic lights, conveyors that start one by one, a washing machine's wash-rinse-spin).

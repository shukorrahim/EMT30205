    L1.1The CPM1A family

    The CPM1A is a small OMRON PLC with its inputs and outputs built in. The family comes in four sizes, and each size comes with either an AC or a DC power supply for the CPU.

    Read the name on your PLC

    Our lab uses this model. Tap each part of the code.

    Tap a part of the code.
    Think of it like a shoe size. The number (10, 20, 30, 40) is the size: how many things the PLC can sense and switch. Bigger sizes (30 and 40) have an expansion port, so you can add more I/O later, like buying shoes with room to grow.

    L1.2Two ways to program it

    You can program a CPM1A with a handheld Programming Console (CQM1-PRO01-E) or from a PC running CX-Programmer, connected through an RS-232C adapter (CPM1-CIF01). Switch between the two below.

    Programming Console: best on site

    • Good for start-up and adjustments where using a PC is nearly impossible.
    • Technicians use it to start or stop an operation on a production line, or to change data that is not part of the main program.
    • Has a key to choose the mode: Run, Monitor or Program (see L1.4).

    PC with CX-Programmer: best for whole programs

    • You see and draw the full ladder diagram on screen.
    • Compile checks your program for mistakes before it reaches the PLC.
    • This is what you use in this lab, through the RS-232C adapter.

    L1.3The training kit: LAMP and SOCKET modes

    L1.4Operating modes: Program, Monitor, RunLab sheet Q1

    The PLC has three modes. On the Programming Console you choose them with a key; in CX-Programmer you click a button. Turn the key and compare what each mode allows.

    Monitor mode

    Think of a bus. Program mode is the bus parked in the workshop: the mechanic can rebuild the engine, but it goes nowhere. Monitor mode is the bus on the road with an inspector on board who can adjust small things while it drives. Run mode is the bus on the road with no one touching the controls.

    L1.5Memory areas (Table 1.1)

    Like a microcontroller, a PLC has memory areas set by the manufacturer. They are the same for every PLC in the family (CPM1A and CPM2A). Every contact and coil in your ladder needs an address in one of these areas, or the PLC will reject the program. Tap an area to see its addresses.

    L1.6I/O port addressing (Table 1.2)Lab sheet Q2

    OMRON addresses I/O by channel and bit. One channel is one 16-bit word, with bits numbered 00 to 15. The address is written channel.bit, and the dot is usually left out: input channel 000, bit 05 is 0.05, or 00005.

    Our PLC has only 12 inputs and 8 outputs, so we use only channel 000 for inputs and channel 010 for outputs. The other channels are reserved for bigger models. Tap any terminal on the PLC.

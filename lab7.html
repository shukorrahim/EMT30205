Linking CX-Programmer and CX-DesignerOne ladder, one screen, one address

L7.1Two programs, one link

In one sentenceCX-Programmer writes the PLC program (the ladder). CX-Designer draws the HMI screen. They are linked through the PLC addresses they share, and integrated simulation lets you test both together on your PC, without a real PLC or HMI panel.
Think of itA lift. The buttons inside the lift (the HMI) only send a floor number. The controller in the machine room (the PLC) decides what the motor does. They work together because they agree on the numbers: "floor 3" means the same thing to both.
(Seperti lif. Butang di dalam lif (HMI) hanya menghantar nombor tingkat. Pengawal di bilik mesin (PLC) yang menentukan apa motor lakukan. Kedua-duanya bekerjasama kerana bersetuju pada nombor yang sama: "tingkat 3" bermaksud perkara yang sama bagi kedua-duanya.)

L7.2The address is the link

In one sentenceAn HMI object does nothing by itself: a bit button writes ON/OFF to a PLC address, and a bit lamp reads a PLC address. If the address on the screen and the address in the ladder are the same, they are linked.

The ladder below is fixed: input 0.00 turns on output 10.00. Hold START on the HMI screen. Then change the address of the button or the lamp and try again. Which addresses make the motor lamp work?

L7.3Step 1: write the ladder in CX-Programmer

In one sentenceMake the PLC program first: choose the PLC model, draw the rung, compile it, and save it where you can find it again.

We use a small example: an HMI button on 0.00 runs a motor lamp on 10.00. Step through it, then do the same on the lab PC.

L7.4Step 2: draw the screen in CX-Designer

In one sentenceMake a new screen, place a bit button and a bit lamp, and give each one the same address you used in the ladder.

How to place and set up objects is in Chapter 5 (5.2 to 5.5). Here we only build what the link needs.

Same bit, two ways of writing it. CX-Designer writes the PLC name (SERIALA) and the word with 5 digits:

L7.5Step 3: link them and test

In one sentenceIn CX-Designer open Tools → Test…, choose Connect to CX-Simulator and pick your CX-Programmer project (integrated simulation). The ladder runs in CX-Simulator, the screen opens in test mode, and pressing a button on the screen runs your ladder.
Remember: Start testing offline only tests the screen by itself, with nothing behind it. To link with your ladder you must choose Connect to CX-Simulator.

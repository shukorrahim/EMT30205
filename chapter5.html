5.2How the HMI talks to the PLC

Key ideaThe HMI keeps reading the PLC addresses shown on the screen, over and over. When the operator presses something, it writes a new value into the PLC. The PLC program does the rest.
Analogy: lockers with numbersThe PLC memory is a wall of numbered lockers. The HMI keeps opening the lockers it shows (read), and when you press a button it puts a new note into a locker (write). The address is the locker number. (Memori PLC ialah dinding loker bernombor. HMI terus membuka loker yang dipaparkannya (baca), dan apabila anda menekan butang ia meletakkan nota baharu ke dalam loker (tulis). Alamat ialah nombor loker.)

    5.5Tutorial 2: the production counter

    Key ideaThe HMI and the PLC work as a team: the operator sets a target on the HMI, the PLC counter does the counting, and the HMI shows the count and lights a lamp when the target is reached.
    Tutorial 2, Soalan 2: Apabila sejumlah nombor dimasukkan dengan menekan bit button, numeric display akan memaparkan jumlah nombor tersebut. Setelah kiraan nombor tersebut mencapai had yang telah dilaraskan pada numeric entry, bit lamp akan menyala.
    Each press of the bit button adds one to the count shown on the numeric display. When the count reaches the limit set on the numeric entry, the bit lamp lights.
    Step 1 · Numeric entryThe operator types the target into the HMI.
    Step 2 · Bit buttonEach press (or each product) sends a count pulse.
    Step 3 · PLC counterThe PLC counts; the numeric display shows the live total.
    Step 4 · Bit lampWhen the count reaches the target, the lamp lights.

    Good to know: an OMRON CNT counter counts down. Its present value (PV) starts at the set value (SV, here from DM0100) and drops by 1 at each pulse; when PV reaches 0 the counter turns ON. The HMI shows SV − PV so the operator sees the count going up.

    5.6Tutorial 2: three products in three hours

    Key ideaA good HMI puts a complex job on one clear overview screen: which product is running, which is next, and how many have been made.
    Tutorial 2, Soalan 1: Dalam masa 3 jam, sebuah mesin menghasilkan 3 jenis produk yang berlainan dari segi saiz dan bahan. In 3 hours one machine makes 3 products: Product 1 40 mm × 40 mm (iron), Product 2 30 mm × 30 mm (plastic), Product 3 50 mm × 50 mm (aluminium). Solve it with an HMI.
    1 hour here = 20 seconds
    MACHINE M-1 · BATCH OVERVIEWShift time 0:00 / 3:00
    Ready to start

    For this example each product runs for one hour. The real split and rates would come from the production plan.

    Which components did this screen use?

    Bit lamps

    Green = running now, amber = next (standby), grey = scheduled, blue = finished.

    Numeric displays

    The count of each product and the shift clock, read from PLC counters and a timer.

    Word and screen buttons

    A word button could select the product number; a screen button could open each product's detail screen.
